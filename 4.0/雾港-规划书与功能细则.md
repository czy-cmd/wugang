## 1. 总规划

### 1.1 定位

网页文字冒险。核心不是吓人，是**让玩家怀疑自己记住了什么**。所有系统围绕「记忆」：记忆值、名册、纸条规则、图鉴乱码。

### 1.2 技术选型

| 项 | 决定 | 理由 |
|---|---|---|
| 形态 | 单个 `index.html`（内联 CSS/JS） | 静态托管直接跑 |
| 依赖 | 0。无框架、无 CDN、无构建 | 离线可跑，发布零配置 |
| 存档 | `localStorage`，key `wugang.save.v1` | 无后端，0 成本 |
| 资源 | `assets/` 两个本地文件，相对路径 | 禁止 `F:\` 绝对路径 |
| 兼容 | 移动端优先，触屏 + 键盘均可 | 参照方块冲刺 |
| 音频 | `<audio>`，首次交互后 `play()` | 绕开自动播放限制 |

### 1.3 交付目录结构

```
文字微恐\
├─ 雾港-规划书与功能细则.md   ← 本文件（不发布）
├─ 雾港-场景全文.md           ← 15 场景 × 3 档正文（不发布，写码时转 JS 数据）
├─ index.html                 ← 下轮产出，唯一入口
└─ assets\

   └─ glitch_bg.jpg           ← 从 F:\ 复制
```

### 1.6 一局流程

```
主页 → 开始游戏 → 场景 1…15（正文打字 → 选项浮出 → 写状态）
     → 结局判定 → 结局文本 → 图鉴落格 → 回主页（周目 +1）
```

- 雾 1→2：进老家看到纸人脸变成林晚。
- 雾 2→3：义庄正厅移开棺材。
- 周目 1 完整弧线；周目 2 起点 2；周目 3+ 全程 3，低浓度文本作「回忆碎片」随机闪现。

### 1.7 红线

1. **不解释**。纸人、铜镜、czy 是谁，游戏不回答。
2. **不扑脸**。恐怖来自痕迹。
3. 不写「你害怕」，只写生理反应与「数量不对」。
4. 不显示雾浓度、记忆值数字（高级面板除外）。
5. 抖动、闪烁低频（约 6 秒一次）。
6. 林晚不直接说话；czy 的声音不描述来源。
7. 定调场景（1 / 5 / 12 / 14 / czy 对话）已由我方按素材原样或准则写定，可再改。

## 2. 打字机引擎

### 2.1 覆盖原则

全站每段可见文字逐字打出：菜单、按钮、设置项、图鉴、结局、提示、命令输出、乱码。例外见 §2.6。容器（按钮框、面板、弹窗）的淡入是独立动画，与文字并行。

### 2.2 渲染参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 每字间隔 | 30 ms | **设置里可调**：慢 60 / 正常 30 / 快 15 / 瞬时 0 |
| 光标 | 8×16 px，`steps(1)` 0.6 s 闪烁 | 恐怖皮转红 |
| 逐字方式 | `textContent += char` + `setInterval` | 不用 `innerHTML` 拼正文 |
| 段落间隔 | 400 ms | |
| 重恐附加 | 每字 40~45 ms，个别句后 700 ms | 浓度 3 自动放慢，不告知 |
| 输出容器 | 单行 `#typeLine` + 历史 `#log` | 打完搬进历史区 |

### 2.3 队列 / 跳过 / 回看

- 队列串行，不允许两段同时打字。
- 点击 / 空格 / Enter：当前段立即补全；再按推进下一段。
- 长按 300 ms 后连续快进。
- 自动跳过已读（设置项，周目 2+ 生效）。
- 历史区保留 200 段，可滚动，不打断当前打字。
- 打字中禁用选项点击，光标停止后才可点。
- 无障碍：`aria-live` 放历史区；「减少动态效果」时整段直出。

### 2.4 中文标点节奏

| 字符 | 额外停顿 |
|---|---|
| `，` `、` `；` `：` | +120 ms |
| `。` `！` `？` | +220 ms |
| `…` `——` | +320 ms |
| 换行 / 段落 | +400 ms |
| `「」` `“”` 内侧首字 | +60 ms |

### 2.5 与容器动画

文字逐字 = 打字机；容器淡入 / 缩放 = CSS 动画。并行，容器不等文字。按钮在文字打到第 3 个字时淡入。

### 2.7 长文本性能

单场景正文约 300~600 字，逐字 30 ms 约 10~18 s。用 `requestAnimationFrame` 批处理（每帧最多 3 字），避免 `setInterval` 在后台标签页堆积；切回前台从当前字继续。

### 4.2 三档与周目

- 三档是**换信息密度**：微恐给暗示，中恐给明确威胁，重恐写主角自身在变化。
- 周目 3+ 全程 3；低浓度文本作「回忆碎片」随机闪现（字色更淡 + 例外 6 一次闪帧）。
- UI 不出现「微恐/中恐/重恐」字样，不显示浓度数字。

### 4.6 结局判定

判定输入：`keys[]` + `clues[]` + `memory` + `flags{}` + `loop` + 最终选择 + `endings` 总数。

优先级（自上而下，先命中先出）：

1. **强制失败**：`memory <= 0` → 21；中恐被守夜人抓住 → 14；地宫停留超时 / 多次进灯塔 → 15；`wall_believed` 且拜堂 → 23。
2. **元叙事**：持 `wood` 且在 czy 对话做出选择 → 39 / 40 / 41 / 42 / 45。
3. **真结局**：全 35 线索 + 高潮「铭刻名字」→ 26；「一起消失」→ 27；全线索 + `memory ≥ 60` + 特定组合 → 38。
4. **浓度 3 线**：按钥匙与选择 → 22 / 24 / 25 / 28~37。
5. **浓度 2 线**：→ 9~20。
6. **浓度 1 线**：→ 1~8。
7. **彩蛋**：`endings` 已 48 且重开 + `copper` + 高记忆 → 44（灯塔顶层自动）。

逐条前置条件以《结局表》为准，写码时**逐条硬编码**，不在代码里临时发明条件（准则 §五.6）。失败的结局也必须告诉玩家死在哪条规则上（`wall_believed` / `name_taken` 等）。

## 6. 高级（英文新语法）

### 6.1 流程

```
主页「高级」→ 警告页（确定 / 取消）
   → 密码页：输入框 + 确认
        密码 = wugang  → 命令面板
        其它          → 停留，回一行「纸条上没有这一条。」
   → 命令面板：输入框 + Enter + 输出区(.code) +「书」+ 关闭
```

- 每次执行命令前走黑屏过渡（例外 7）：黑幕 + 抖动 + 独白逐字 + 停留 ≥1 s + 淡出。方块冲刺的英文 `doubts` 弃用，改用 §8.5 中文独白池。
- 输出区文字逐字。
- 密码前端明文，只防误触。刷新页面后需重新输入。

### 6.2 语法总则

| 规则 | 内容 |
|---|---|
| 形式 | 全小写英文，单动词 + 裸参数，空格分隔：`fog`、`fog 3`、`give key copper` |
| 禁用 | `get` `from` `into` `url-` `type` `kb-true` `kb-false` `tp` `about-` `percent` 及一切旧命令 |
| 连字符 | 命令名不用连字符、不用下划线；参数里的标记名保留原样（`entered_dark`） |
| 大小写 | 不敏感 |
| 未知命令 | 「纸条上没有这一条。」 |
| 调试隔离 | 改动只作用于本会话调试态；不写图鉴、不计全收集、不触发彩蛋；只有 `commit` 提交进存档 |

## 8. 恐怖模式

### 8.1 三层视觉结构（按用户定义）

| 层 | 条件 | 表现 |
|---|---|---|
| **基底 A：黑底恐怖皮** | 背景关（**默认**） | 纯黑底 + 血雾暗角呼吸 + 扫描线流动 + 血红 UI（标题/按钮/面板边框 `#ff6a6a` 系）= 方块冲刺恐怖模式那套 |
| **基底 B：图片底** | 背景开 | `glitch_bg.jpg` 全屏 + 暗角 + 低频色差；UI 仍血红 |
| **加强层：动态恐怖** | `bloodSession` 开 | 追加低频独白、故障闪帧、浓度 3 极限暗角、结局质问页、心跳 |

所以打开网站第一眼就是恐怖皮——这是用户要的效果，不是 bug。

### 8.2 触发

- `bgMode`：设置里切，默认 `off`。
- `bloodSession`：`fog` 首次到 3 时自动开；或命令 `blood on`。关：设置页「离开雾港」或 `blood off`。**跨场景、跨周目、跨结局保持，只有主动关闭才结束。**
- 两个变量分离：`fog` 管叙事文本，`bloodSession` 管演出。

### 8.3 参数

| 层 | 参数 |
|---|---|
| 血红 UI | `.blood` 全局类；面板底 `rgba(22,3,3,.94)` |
| 暗角 | opacity .68→1，3.1 s ease-in-out infinite；浓度 3 中心透明区收窄到 12% |
| 扫描线 | 1 px / 4 px，opacity .82，6 s linear 位移 48 px |
| 闪帧 | 6 s 一次，±2 px，120 ms |
| 独白 | 8~14 s 一句，淡入 600 / 停留 2.4 s / 淡出 600，逐字 |

一秒三次是烦躁，六秒一次才是恐怖（准则 §三.5）。

### 8.4 独白池（需人工过一遍）

浓度 1/2：

> 你数过这几行字了吗。／刚才那句，是不是少了一个字。／纸条背面还有字。你翻过了吗。／别回头。主页一直在这。／你确定这是第一遍吗。

浓度 3：

> 她姓什么来着。／雾在变浓。／第 87 个。／有人在写你现在的表情。／键盘声停了一下。

不写怪物、不写「你害怕」、不解释、不描述声音来源。

### 8.5 黑屏独白

复用同一池，随机一句。

### 8.6 结局页质问

> 你还记得她的脸吗？
> （没有回答。光标在闪。）

血光脉动 4.5 s；无眼睛/怪物图形；点一下回主页，`bloodSession` 保持。

### 8.7 红线

恐怖层只改演出，不改雾浓度、记忆值、结局判定。视觉变化不等于显示隐藏数值。
