# 雾港 5.0 · 大纲与功能说明

> 严格分支树：一步错，不可回。每个按钮通向的结局都不一样。

## 一、核心设定

- 你回到「雾港」——一个回不去的镇子。来过的人都会在这里留下一个「替身」：一个纸人、一个名字、一幅画像。
- 核心悬念：你其实早就来过雾港（或早已死过）。这次的「回来」，是了结，还是又一次重复。
- 恐怖手法：数量不对（纸人六个变五个、棺材多一口、名字多一个）、死者在别处复活、墙里藏物、画像榨命、心跳幻听。

## 二、分支树结构

- **46 节点、48 结局、深度 5 步**。
- 根节点 3 选，此后每一层 2 选，第 4 层选择后进入结局。严格树：无汇合、无环、无返回。

| 根选择 | 分支母题 | 结局编号 |
|---|---|---|
| 跟着白灯笼走 | 白灯笼 · 引魂（纸人/冷火/无脸人） | E1–E16 |
| 摸黑走小径 | 义庄 · 替身（棺材/画像/名册） | E17–E32 |
| 把信扔进水里 | 渡口 · 回魂（信/船/雾） | E33–E48 |

## 三、小游戏（9 个，穿插在第 4 层）

三类机制，成功/失败各通向一个不同结局：

| 类型 | 玩法 | 节点 |
|---|---|---|
| 连点（mash） | 限时猛点，点够次数 | 擦脸上的字 / 把照片按回棺材 / 拨开水雾 |
| 时机（timing） | 等指针进区间再点 | 吹熄冷火 / 屏住呼吸 / 撑到对岸 |
| 反应（react） | 闪现后立刻点「闭眼」 | 别和它对上眼 / 别接那幅画 / 别和它对视 |

失败必触发突脸惊吓，并进入「失败」结局。

## 四、恐怖元素（三档）

| 档位 | 突脸 | 尖叫 | 乱码打字 | 额外 |
|---|---|---|---|---|
| 温和 | 无 | 无 | 无 | 纯剧情 |
| 标准（默认） | 有 | 有 | 有 | — |
| 极度恐怖 | 更频繁 | 更响 | 有 | 自动全屏、重暗角、随机微惊吓、结局质问 |

- **极度恐怖模式是独立按钮**：需二次点击，看完约 2000 字免责声明并滚动到底、勾选「我已同意」后才开启。
- 首次进入游戏，默认弹出免责声明：「前往设置」或「开始游戏，我是猛男」。

## 五、其余功能

- 全站逐字打字机 + 乱码显现，速度四档，点击/空格跳过。
- 主页：开始游戏 / 我的结局 / 设置 + 底部「关于 · 全屏」。
- 结局页：结局名 + 已收集数 + 你的路径（5 步）+ 本局恐怖模式 + （极度恐怖时）「你还好吗？」。
- 图鉴：48 格按三根分支分组，点开看「如何进入」。
- 背景默认红门，可切「无（黑底）/ 红门 / 故障图」。
- 全屏：F11 或页面「全屏」按钮。
- ESC 暂停；剧情内无任何返回按钮。

## 六、数据与自检

- 单一数据源 `tree_data.js`；`selfcheck.js` 验证 13 项不变量（严格树/无环/48 结局=叶子/路径一致/小游戏合法）。
- 素材：`assets/`（bgm、glitch_bg、红门、两张鬼脸）。
