# 《雾港》高级使用手册

> 本手册对应 `文字微恐/2.0/index.html` 的高级面板，命令与代码逐条核对。
> 口令：`wugang`（可用 `password <新口令>` 修改）。

---

## 一、怎么进去

1. 主页点 **高级**。
2. 警告页：「这里的东西可能改变你看到的故事。不要在这里待太久。」点 **继续**。
3. 输入口令（默认 `wugang`）。输错只回一行「纸条上没有这一条。」，不提示、不计数。
4. 进入面板：上方输入框、下方输出区、右下角 **命令书**。

每次执行命令前会走一次黑屏过渡（抖动 + 随机独白逐字打出 + 约 1.5 秒），独白从 10 句池里随机抽，例如「你数过这几行字了吗。」「纸条背面还有字。你翻过了吗。」——**这是正常流程，不是卡死**。输出以打字机速度逐字显示，点击或空格可跳过。

## 二、命令总表

命令**不区分大小写**，参数用空格分隔。找不到的词一律回「纸条上没有这一条。」

### 2.1 查看（只读，不动存档）

| 命令 | 作用 |
|---|---|
| `fog` | 当前雾浓度（1~3） |
| `mind` | 记忆值（0~100） |
| `loop` | 当前周目 |
| `where` | 当前场景编号 |
| `seed` | 本局随机种子（每局开局生成，决定细节与选项） |
| `clues` | 已获线索编号列表 |
| `keys` | 持有钥匙（铜/银/铁/木） |
| `rules` | 五条规矩 + 当前违规标记 |
| `ends` | 结局解锁进度（n / 48） |
| `state` | 完整状态 JSON（loop/fog/memory/clues/keys/flags/blood/seed） |

### 2.2 跳转与流程

| 命令 | 作用 |
|---|---|
| `go <1~15>` | 跳到指定场景 |
| `go lighthouse` | 直接进灯塔真相段 |
| `go end <n>` | **播放**结局 n，但不解锁、不进图鉴 |
| `home` / `leave` | 回主页 |
| `back` | 回到上一个场景（注意：只换场景，**不回滚**已改的状态） |
| `retype` | 重播当前场景段落 |

### 2.3 修改状态

| 命令 | 作用 |
|---|---|
| `fog <1\|2\|3>` | 强制雾浓度。注意：`fog 3` 会**连带打开**动态恐怖会话 |
| `mind <0~100>` | 设记忆值 |
| `give clue <编号>` | 发放线索，如 `give clue F07` |
| `give key <copper\|silver\|iron\|wood>` | 发放钥匙，如 `give key silver` |
| `clear rule <标记>` | 清除一条违规标记 |
| `clear all` | 清空全部违规标记 |
| `blood on\|off` | 动态恐怖会话（独白、闪帧、结局质问页） |

违规标记共 6 种：`entered_dark`、`recognized`、`candle_blown`、`mirror_flipped`、`name_taken`、`wall_believed`。

### 2.4 结局调试

| 命令 | 作用 |
|---|---|
| `unlock end <n>` | 解锁第 n 格（标记为调试态） |
| `unlock all` | 48 格全亮（不触发全收集事件） |
| `lock end <n>` | 重新锁上第 n 格 |
| `lock all` | 全部锁上 |
| `commit` | 把调试解锁的格**写入正式存档**（去掉调试标记） |

### 2.5 设置（与设置页互通）

| 命令 | 作用 |
|---|---|
| `speed <0~200>` | 每字毫秒数，`0` 为瞬时 |
| `sound on\|off` | 打字音效 |
| `bgm on\|off` | 背景音乐 |
| `bg <none\|door\|glitch>` | 背景：无（黑底）/ 红门 / 故障图 |
| `shake on\|off` | 故障动效 |
| `password <新口令>` | 修改进入口令 |

### 2.6 存档

| 命令 | 作用 |
|---|---|
| `export` | 导出存档码（base64），自动复制到剪贴板 |
| `import <码>` | 用存档码覆盖当前存档 |
| `erase` | **清空本地存档**，有确认框，无法恢复 |

### 2.7 命令书

| 命令 | 作用 |
|---|---|
| `book` | 展开 / 收起命令书 |
| `help` 或 `?` | 展开命令书 |

## 三、调试态规则（重要）

高级面板默认处于**隔离调试态**：

- `unlock end` / `unlock all` 解锁的结局都带 `tainted` 标记，图鉴里能看，但**不算「真正收集」**。
- 只有 `commit` 会把它们转正（输出「commit. 写下了。」）。
- `go end <n>` 播放结局但完全不写存档——想截图/看文案时用这个，干净。
- `lock all` 会把结局记录直接清空，正式收集也一起没，慎用。

> 设计意图：高级是观测工具，不是作弊器。转不转正，由你决定。

## 四、常用配方

**看某段结局文案（不污染存档）**
```
go end 24
```

**调试场景 12 重恐档**
```
fog 3
go 12
```

**补一把银钥匙继续推真结局**
```
give key silver
go 15
```

**把所有格点亮做图鉴截图**
```
unlock all
home
```
（不进 `commit` 就是纯调试态，随时 `lock all` 清掉）

**打字太慢想扫剧情**
```
speed 0
```

**换回黑底恐怖皮**
```
bg none
blood on
```

## 五、隐藏命令（命令书里没有）

| 命令 | 作用 |
|---|---|
| `write <文字>` | 在墙上写一句话（写进 wallNotes，本地留存） |
| `ask` | 直接打开 czy 对话层 |
| `stop` | 直接进入结局 40「别写了」 |

---

## 六、注意事项

1. **`erase` 不可恢复**。执行前它会弹确认框，看清楚再点确定。
2. **口令是明文存在本地存档里的**，`password` 只防误触，防不住有心人。
3. `export` 出来的码就是一整份存档的 base64，别随便发给别人。
4. `fog 3` 有副作用：会连带打开动态恐怖会话（血雾闪帧、独白、结局质问页）。想只改浓度不改氛围，用 `fog 3` 后接 `blood off`。
5. `back` 是场景回退，不是状态回退——改坏的状态它救不回来，只能手动改回去。
6. 黑屏过渡的 1.5 秒里输入框不接受新命令，等独白打完。
7. 所有修改**立即写本地存档**（localStorage），刷新不丢；换浏览器/清缓存会没，重要进度先 `export`。

其它   book | help | ? | write | ask | stop
