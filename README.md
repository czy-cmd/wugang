# 雾港

一个网页文字恐怖游戏。单文件 HTML，无依赖、无构建，打开即玩。

> 《雾港》是一个虚构的故事。镇子不存在，纸人不存在，规矩也不存在。
> 里面的人都是写的。本作含心理恐怖与死亡描写。

## 在线游玩

GitHub Pages（启用后填写）：

```
https://czy-cmd.github.io/wugang/
```

## 本地运行

直接双击 `4.0/index.html` 即可，无需服务器。

或起一个本地服务：

```bash
cd 4.0
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 玩法

- **开始游戏**：15 个场景固定线性推进，选项只改变记忆、线索与钥匙，不跳场景。
- **每局都不同**：每局生成随机种子，场景细节、线索位置、选项组合都会变化；二周目起追加新选项（如「这封信我好像看过」）。
- **我的结局**：48 个结局图鉴，按雾浓度分组。结局页显示「已收集 X / 48」。
- **实验性玩法**：3 个独立短篇异闻，仅试玩，不写存档、不计周目、不收录结局。
- **设置**：打字机速度四档、乱码打字、背景（无/红门/故障图）、BGM、打字音效、故障动效等。
- **关于**：主页底部小字，内含虚构性声明。

### 高级面板

主页 → 高级 → 口令 `wugang`。英文命令全套（`fog`、`go 5`、`give key silver`、`unlock end 24`、`commit`、`speed 60` 等），
完整命令说明见 [`4.0/雾港-高级使用手册.md`](4.0/雾港-高级使用手册.md)。

├── index.html            Pages 入口（自动跳转 4.0）

├── 1.0/                  初版
├── 2.0/                  每局随机化 + 新 GUI + 实验性玩法

存档保存在浏览器 localStorage，换设备/清缓存会丢失，可在高级面板用 `export` / `import` 迁移。
