# 雾港

一个网页文字恐怖游戏。无依赖、无构建，打开即玩。

> 《雾港》是一个虚构的故事。镇子不存在，纸人不存在，规矩也不存在。
> 里面的人都是写的。本作含心理恐怖与死亡描写、突脸惊吓（jump scare）。

```
https://czy-cmd.github.io/wugang/
```

## 当前版本（6.0）

- **204 个结局**：基础 192 + 旁支 12，深度 7 的严格分支树（190 节点），末层部分节点 3 选。
- **结局 9 类**：TE / GE / NE / PE / OE / SE / DE / FE / CE，每类不少于 10 个；结算页显示类型标签（颜色 + 中文名）。
- **两个隐藏结局**：H1「虚假的游戏」、H2「美丽的红门」（IE 类型），收录于图鉴第 5 个「隐藏」标签页。
- **8 种小游戏**：连点 / 时机 / 反应 / 闪避 / 记忆 / 按住 / 接住 / 稳住，末层节点随机触发，带「有人发现了你」随机事件感。
- **恐怖四档**：温和 < 正常 < 地狱 < 惧渊临境；惧渊临境锁死下拉框、关闭需连点 3 次 + 怪物阻难动画。
- **幻文三档**：关闭 / 开启 / pro；pro 为彩蛋文案（自我怀疑、隐藏结局暗示）+ 更密集、更快、字号更大。
- **时间线三位置**：下方横滚 / 侧边竖排 / 底部细线，设置可自选；另有实验性分支树视图。
- **加长免责声明**：滚动式分章节协议（含完整法律条款）。
- **每节点 3 变体台词**。

## 本地运行

直接双击 `6.0/index.html` 即可，无需服务器。

或起一个本地服务：

```bash
cd 6.0
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```

├── index.html            Pages 入口（自动跳转 6.0）

└── 6.0/                  当前版本（204 结局 + 9 类 + 四档恐怖 + 8 小游戏 + 双隐藏）
    ├── index.html        游戏本体
    ├── tree_data.js      剧情树数据（190 节点 / 204 结局）
    ├── groups_data.js    图鉴分组（主线 3 组 + 旁支 + 隐藏）
    ├── gen_tree6.py      剧情树生成器
    ├── selfcheck.js      不变量自检
    └── assets/           bgm.mp3、突脸图、红门等素材
```

存档保存在浏览器 localStorage，换设备/清缓存会丢失。
