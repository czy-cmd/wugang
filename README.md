# 雾港

一个网页文字恐怖游戏。单文件 HTML，无依赖、无构建，打开即玩。

> 《雾港》是一个虚构的故事。镇子不存在，纸人不存在，规矩也不存在。
> 里面的人都是写的。本作含心理恐怖与死亡描写、突脸惊吓（jump scare）。

## 本地运行

直接双击 `5.0/index.html` 即可，无需服务器。

或起一个本地服务：

```bash
cd 5.0
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 玩法（5.0 严格分支树版）

- **一步错不可回**：严格分支树，每个选项唯一分叉、永不汇合、无环、无返回。每个按钮通向的结局都不同。
- **48 个结局**：5 步走完，三根分支各有母题；结局页与图鉴都展示「如何进入」的达成路径。
- **小游戏**：连点（擦字/按棺材/拨水雾）、时机（吹冷火/屏息/撑船）、反应（闪现后点闭眼），成功/失败通向不同结局。
- **恐怖突脸**：小游戏失败必突脸 + 尖叫 + 屏幕震动；极度恐怖下随机微惊吓。
- **恐怖三档**：温和 / 标准（默认）/ 极度恐怖。极度恐怖需二次确认 + 滚动到底阅读免责声明 + 勾选同意。
- **首次免责声明**：第一次打开弹「开始之前」，可「前往设置」或「开始游戏，我是猛男」。
- **设置**：打字机速度、乱码打字、背景（默认红门）、BGM、打字音效、故障动效、全屏等。

```
├── index.html            Pages 入口（自动跳转 5.0）

```

存档保存在浏览器 localStorage，换设备/清缓存会丢失。
